# 스트레스 테스트 (6·30 시스템) — 견고성·한계

> `examples/demo_stress.py` 산출. 민감도가 '그럴듯한 범위' 섭동이라면, 스트레스는 **극단·경계·대량·적대적** 입력이다. 통과가 완벽을 뜻하지 않으며, 깨지는 경계를 수치로 보고한다.

## 1) 극단 시나리오 배터리 (불변식 유지)

| 시나리오 | 강화 | 검토 | 산정불가 | 감소율 | 불변식 |
|---|---|---|---|---|---|
| 전원 무주택 일반(최대 강화) | 100% | 0% | 0% | 42.9% | ✓ |
| 전원 생애최초(예외 유지) | 0% | 0% | 0% | -0.0% | ✓ |
| 전원 서민·실수요 | 100% | 0% | 0% | 14.3% | ✓ |
| 전원 비처분 유주택(명세 여백 최대) | 0% | 100% | 100% | — | ✓ |
| 전원 다주택 | 0% | 100% | 100% | — | ✓ |
| 전원 경과규정(종전규정) | 0% | 0% | 0% | -0.0% | ✓ |
| 전원 정책대출(Discovery) | 0% | 0% | 100% | — | ✓ |

> 불변식: 방향 비중 합=1 · 산정불가 0~1 · 여력 감소율 음수 아님 · 가중 합 보존. 전 시나리오에서 유지(명세 여백은 산정불가 100%로 정직 분리).

## 2) 역(逆)스트레스 — 결론이 뒤집히는 경계

- **강화 과반:** 무주택 일반 비중의 **20%**를 다주택으로 옮기면 깨진다
- **여력 축소:** 스윕 전체 최소 감소율 **13.1%** → **구조적으로 뒤집히지 않음**(어떤 구성에서도 여력이 증가하지 않음 — 6·30에 완화 항목이 없기 때문).

> 이것이 정직한 한계 보고다: 방향 결론(여력 축소)은 구조적으로 견고하지만, 특정 수치 주장('강화 과반')은 모집단 구성 가정에 따라 깨질 수 있다.

## 3) 차등 퍼징 — 무작위 입력에서 엔진 견고성

- 무작위 신청 **5,000건**(미상 지역 포함): 크래시 **0** · 무효상태 **0** · 알려진 지역 오라클 비교 3,010건 중 불일치 **0**.
- 상태 분포: DECIDED 959, DISCOVERY 467, NEEDS_HUMAN_REVIEW 1,063, OUT_OF_SCOPE 2,511.

> 무작위 입력에서도 엔진은 예외 없이 **항상 유효한 상태**를 반환하고, 독립 오라클과 **전건 일치**한다(스펙 도메인 내). 미상 지역도 크래시 없이 처리.

## 4) 대규모 부하

- **50,000건** 엔진↔오라클 불일치 **0** (0.23s · **217,050건/s**).
