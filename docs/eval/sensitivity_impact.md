# 비중/가격 민감도·견고성 분석 (6·30) — 실측 리포트

> `examples/demo_sensitivity.py` 산출. 임팩트/여력의 헤드라인 결론이 **문서화된 가정**(아키타입 비중·지역 mix·담보가격 분포/수준)에 얼마나 **견고한가**를 측정한다.

## 정직성 고지

- 이것은 **문서화된 가정 입력에 대한 민감도**이지 **실세계 불확실성의 정량화가 아니다**(실측 데이터 없음).
- **룰엔진·LTV 로직·시행일·경과규정은 절대 흔들지 않는다** — 사람이 확정한 사실이지 가정이 아니다. 민감도는 오직 예시적 모집단·가격 구성에만 가한다("확정 규칙 고정, 가정 입력만 스트레스").
- 섭동 범위(아키타입 ±50%, 담보가격 ±30%, Dirichlet 집중도 40, 가격 수준 로그정규 σ0.20)도 **문서화된 가정**이다.

**핵심 관찰**

- **여력 감소율(%)**은 오직 **아키타입 비중**(특히 무주택 일반)이 좌우한다. **담보가격 수준·지역 mix는 영향 0** — 아래 '가격 불변성' 참조.
- **1인당 Δ여력(억)**은 반대로 **담보가격 수준**이 최대 driver다(절대 금액이 가격에 비례). 같은 출력이라도 비율(%)이냐 수준(억)이냐에 따라 driver가 뒤바뀐다.
- **사람검토/산정불가 비중**은 유주택·다주택·정책대출 비중이 좌우한다(여력 금액엔 안 들어가는 셀).

## 2) 헤드라인 밴드 + 결론 견고성 (몬테카를로)

```
몬테카를로 민감도 밴드 (n=3000, 가정 섭동만·규칙 고정)
정직성: 문서화된 가정에 대한 민감도이지 실세계 불확실성 정량화가 아님(실측 없음).

지표                  base        P5       P50       P95
------------------------------------------------------
강화 비중              58.0%     45.2%     57.8%     70.3%
사람검토 비중            23.0%     13.0%     22.5%     34.0%
가중평균 Δ           -20.0pp   -23.6pp   -20.0pp   -16.0pp
여력 감소율             28.6%     22.9%     28.6%     33.8%
1인당 Δ여력           -2.02억    -3.02억    -1.99억    -1.32억
산정불가 비중            23.0%     13.0%     22.5%     34.0%
------------------------------------------------------
결론 견고성(가정 범위에서 성립한 표본 비율):
  ✓ 여력 축소(감소율>0): 100.0%
  ✓ 1인당 여력 감소(Δ<0): 100.0%
  ✗ 강화 과반(강화>50%): 84.9%
```

**해석**

- **방향 결론은 견고하다:** 여력 축소(100%)·1인당 여력 감소(100%)가 **전 표본에서 성립**.
- **크기는 밴드로 말한다:** 여력 감소율 base 28.6%, P5–P95 **[22.9%, 33.8%]** — 점추정 과잉확신 대신 밴드.
- **가정-취약한 결론도 정직하게 표기:** '강화 과반(>50%)'은 85% 표본에서만 성립 → 무주택 비중 가정에 따라 흔들리는 결론(방향과 달리 견고하지 않음).

## 3) 가격 불변성 (Model Risk 인사이트)

- 담보가격을 세그먼트와 **독립·균일**하게 적용하므로, **여력 감소율(%)은 담보가격 수준에 불변**이다: ±30%를 흔들어도 감소율 스윙 **0.0%**(사실상 0).
- 반면 **절대 금액(억)은 가격에 비례**한다: 같은 ±30%에서 1인당 Δ여력 스윙 **+1.21억**.
- **함의:** 감소율은 **모집단 구성**의 진술이고, 억 금액은 **가격 가정**까지 얹은 진술이다. 보고 시 둘을 구분해야 한다(감소율은 상대적으로 견고, 억 금액은 가격 가정에 종속).
