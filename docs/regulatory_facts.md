# regulatory_facts — 규제 사실의 단일 기준점

> **이 파일은 골드셋 · 룰엔진 · Rule Change Proposal이 공유하는 사실의 단일 출처(single source of truth)다.**
> 세 곳에서 사실을 각각 손으로 넣으면 반드시 어긋난다. 사실은 여기서만 정의하고 나머지는 참조한다.
>
> ⚠️ **상태: 스켈레톤.** 각 claim의 원문 인용·URL·hash·확신도는 **사용자 도메인 검수 후 확정**한다 (`03_OPEN_QUESTIONS.md` Q6).
> ⚠️ 이 프로젝트의 브랜드는 "Assurance"다. **여기 사실이 하나라도 틀리면 전체 신뢰가 무너진다.** 확정 전에는 골드 정답으로 쓰지 말 것.

## 사실(fact) vs 모의(mock)의 경계 — 반드시 구분

- **사실(fact):** 실제 정부·감독기관이 발표한 공개 규정. 원문 인용·URL 필수. (예: 6·30 규제지역 지정, LTV 40%)
- **모의(mock):** 은행 내부 여신정책·내규. 실제 회사 문서를 쓰지 않으므로(LOCKED §8) **공개 감독규정에 기반해 직접 작성한 모의 문서**로 대체. 산출물에 "mock policy" 명시.
- 산출 수치에는 항상 "synthetic portfolio 결과"를 명시 (브리프 §14).

### 🔺 원문이 교정/보강한 사항 (사용자 확인 필수)
1. **생애최초 = LTV 70% (좌동)** — 브리프 "60~70%"는 완화범위 표현. FAQ Q2 표는 생애최초를 **70%로 명시**. (규제지역에서도 강화 안 됨, 단 한도·전입의무는 적용)
2. **서민·실수요자 = 60%** — 브리프에 없던 별도 구간. (부부합산 연소득 9천↓·주택가격 8억↓·무주택세대주)
3. **유주택(비처분 1주택 이상) 규제지역 = LTV 0%** — 브리프는 "다주택"만 언급했으나, 원문(MOLIT p3)은 **유주택 0%**. → 룰 R5 해소.
4. **토지거래허가구역 효력 = 7.5일** (투기과열·조정은 7.1일). 브리프는 토허제도 6.30 근처로 뭉뚱그림.
5. **정책성 대출은 상품별 상이** — 디딤돌 70% / 보금자리론 규제지역 아파트 60%(생애최초·실수요자는 좌동). 단일값 아님.
6. **추가 제약(코어 밖, 기록만):** 최대한도 주택가격 구간별(15억↓ 6억/15~25억 4억/25억↑ 2억), 전입의무 6개월, 만기 30년, DTI(조정 50%/투기 40%), DSR(은행 40%/2금융 50%).
7. **집단대출 경과규정** 별도 분기(입주자모집공고·착공신고·관리처분인가 기준).
