# RegImpact AI — 포트폴리오 요약

> **생성형 AI 기반 주택담보대출 규제 변경 영향분석 · 검증 시스템**
> 금융권 Model Risk / 모델검증 / AI Governance / AI Assurance / AI Evaluation 직무 지원용

---

## 한 줄 정의

**규제가 바뀌면 무엇을 고쳐야 하는지 AI가 초안하고, 그 초안이 틀리지 않았음을 검증 가능하게 증명하는
의사결정 지원 시스템.** 챗봇이 아니라, **사람이 확정한 결정적 룰엔진** 위에서 도는 Assurance 파이프라인.

## 문제

주택대출 규제(예: 2026-06-30 규제지역 추가 지정)가 바뀌면 은행은 공문에서 **정확히 무엇이 바뀌었는지**를
빨리 읽어 **여신 룰·고객·내규·테스트**에 반영해야 한다. 사람 수작업은 누락 위험이 크고, LLM 전면 위임은
**환각**이 여신 결정을 조용히 오염시킨다. 이 프로젝트는 그 사이의 **"검증 가능한 중간"**을 구현한다.

## 접근 — 세 겹 구조

```
[AI 초안]  →  [사람이 확정한 결정적 규칙]  →  [검증층이 감시]
Extractor      Rule Engine                  Assurance
"뭐가 바뀜?"   "그래서 LTV 얼마?"            "그 말 진짜야?"
```

1. **AI는 초안만** — 실제 LTV 판정·규칙 값은 사람이 확정한 명세에서 온다(자동 규칙 생성 없음).
2. **모르면 표면화** — 규칙 미정의(명세 여백)는 임의값 대신 "사람 검토"로 escalation.
3. **모든 주장은 근거 대조** — AI 인용이 원문에 실재하는지 기계 검증(환각 탐지).

**파이프라인:** 공문(해시) → 추출 → 인용검증 → 지역정규화 → 룰엔진(전/후) → 임팩트 → 여력 금액 →
민감도 → 룰 변경안 → 내규 영향도 → 리포트/증거.

## 핵심 성과 (6·30 실측 — 실제 파이프라인 출력)

| 영역 | 결과 |
|---|---|
| 추출 신뢰 | Citation **100%** · 환각 **0%** · 변경완전성 **100%** · 예외재현 **100%** |
| 룰엔진 검증 | 독립 오라클 차등검증 **178/178** + 몬테카를로 **5,000/5,000** |
| 고객 영향 | 가중 강화 58%·유지 24%·검토 18% (Δ −20pp) |
| 영향 금액 | 1인당 여력 7.08억→5.06억 (**−28.6%**), 민감도 밴드 [22.9%, 33.8%] |
| 내규 영향도 | 모의 내규 13건 → 수정필요 9·검토 1·간접 1·**무관 2**(과잉플래그 없음) |
| 스트레스 | 퍼징 5,000건 크래시 0·불일치 0 / 부하 50,000건 불일치 0 |
| 품질 | 테스트 **162 통과**, 런타임 의존성 **0** |

## 역량 매핑

- **모델검증 / Model Risk** — 독립 명세 오라클 차등검증(자기채점 아님), mutation test, 위험차등 임계값
  정책(하드게이트), error taxonomy(E1~E9), **검증보고서 5축**(개념·구현·성과·거버넌스·재현), 스트레스/역스트레스.
- **AI Assurance / Evaluation** — Citation grounding(환각 탐지), 층화 골드셋 178 + DEV/LOCKED/CHALLENGE
  3분할, 지표 정의·분모·임계 명세, **측정 아티팩트 자체 탐지·수정**(채점기 결함 67%→100%).
- **AI Governance** — AI초안→사람확정(승인 PENDING), 명세 여백 escalation, 감사추적(라이브파이어 증거:
  원문 해시·timestamp·commit), 한계·가정 정직 표기.
- **금융 도메인** — 주담대 LTV 규제 룰엔진(경과규정·예외·지역 시점해석), 여신 룰·내규 영향 전파.

## 특징적 강점 (검증자 관점)

- **검증이 tautology가 아니다** — 룰엔진을 **독립 구현 오라클**과 대조(엔진 미import). 둘이 100% 일치할 때만 통과.
- **정직한 한계 보고** — "여력 축소"는 가정 섭동에서 **구조적으로 견고**(100%), "강화 과반"은 **85% 표본만**
  성립. 뒤집히는 경계(역스트레스)까지 수치로 공개.
- **측정 도구 자체를 검증** — 초기 Citation 67%가 모델 오류가 아니라 **채점기 정규화 결함**임을 규명·수정·회귀방지.
- **재현·감사 가능** — 리포트 값은 엔진/추출 실제 출력에서만(하드코딩·환각 불가). 원문 sha256이 레지스트리와 일치.

## 기술

Python(표준 라이브러리만, **런타임 의존성 0**), pytest(162), 결정적 시뮬레이션(seed 고정),
LLM structured output(Google AI Studio, REST/urllib), 자체완결 HTML 리포트·inline SVG 차트(zero-dep).

## 정직성 · 범위

단일 정책 seed(6·30) 기준이며 독립 3자 벤치마크가 아니다. 모집단·담보가격은 **문서화된 가정**(실측 아님,
공개자료만 사용). 여신 최종 결정은 사람 승인을 거친다. 미확정 사실(규제 permalink 등)은 임의 생성하지 않는다.
