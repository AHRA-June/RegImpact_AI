## 제출 전 사람이 확인할 것

- **형식** — 영상은 `webm` 뿐이다. 제출처가 mp4 만 받으면 변환이 필요하다
  (2026-08-23 기준 이 실행 환경에는 ffmpeg 이 없었다).
- **무음** — 대본(`../APPLY_TOMORROW_CHALLENGE.md` §3)대로 내레이션을 얹어 다시 찍는 편을
  권한다. 무음 화면만으로는 "왜 이게 다른가"가 전달되지 않는다.

## 다시 만들려면

```bash
npm install pptxgenjs          # 저장소는 pptxgenjs 를 담지 않는다
pip install -e ".[ui]"         # 녹화용 playwright

python tools/deck_facts.py --out deck_facts.json
node   tools/build_deck.js deck_facts.json 내한도시그널_서비스소개서.pptx

python tools/build_site.py --out site
python tools/record_demo.py --site site --out 내한도시그널_데모.webm
```

**화면이나 수치가 바뀌면 이 사본은 그 순간 낡는다.** 2026-08-21 점검에서 실제로
그런 일이 있었다 — 6단계에 '지켜보기'가 들어갔는데 녹화본은 그 전 화면이었고, 덱의
테스트 수는 590 에 멈춰 있었다. **제출 직전에 위 명령으로 한 번 다시 뽑아 대조하는 것이
가장 안전하다.** 덱 수치는 손으로 적지 않고 `tools/deck_facts.py` 가 엔진을 돌려 만든다.
