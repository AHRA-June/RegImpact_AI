검증 (Assurance)
지표는 LLM 자기채점이 아니라 원문 대조·사람 확정 골드·독립 명세 오라클로 산출된다.
이 페이지는?
무엇을 보는 화면인가요?
AI와 심사 엔진이 낸 답이 맞는지 채점한 성적표입니다.
무엇으로 만들었나요?
원문 대조기 + 사람이 확정한 정답지 + 명세에서 따로 만든 독립 검산기. AI가 스스로 채점하는 게 아니라, 독립된 기준 세 가지로 채점합니다.
어떻게 보나요?
각 지표를 확정 기준(임계)과 비교해 통과/미달을 판정합니다. 자동으로 넘기지 않고 사람에게 올린 항목은 아래 Escalation 목록에 이유와 함께 있습니다.
